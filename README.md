# 规则之书·简版（rule-book-lite）

一个极简的 SillyTavern 第三方扩展：带 UI 面板管理 **世界规则 / 区域规则 / 个人规则 / 区域 / 建筑 / 角色**，已启用的规则自动注入 AI 上下文，数据可通过 **GitHub 私有仓库** 在多设备间同步，每次同步产生一条 commit，天然保留历史。

UI 风格参照「规则修改器」前端（暗色锌灰 + 蓝/青徽章卡片），功能大幅精简，不依赖 MVU、酒馆助手或任何正则脚本。

## 功能

- 右下角浮动 📖 按钮打开面板
- 导航栏：全部规则 / 区域规则 / 个人规则 / 区域 / 建筑 / 角色 / 已启用 / 设置
- 卡片实时显示「已启用 / 已停用」徽章，一键启停（另设「已启用」导航页汇总）
- 「已启用」的规则按固定模板注入聊天上下文（世界既定事实 + 记忆合理化原则）
- GitHub 同步：按条目 ID + 修改时间做 last-write-wins 合并；本地删除不会被远端复活
- 设置页可查看同步历史（commit 列表）、导出 / 导入 JSON 兜底

## 安装

**方式一（推荐，便于多设备安装）**：把本文件夹上传到你自己的 GitHub 仓库（代码仓库，可公开），然后在酒馆「扩展 → 安装扩展」粘贴仓库地址，刷新页面。

**方式二（本机手动）**：把本文件夹复制到
`SillyTavern/public/scripts/extensions/third-party/rule-book-lite/`
（文件夹内直接包含 manifest.json），刷新页面。

## GitHub 同步配置（面板 → 设置）

1. 新建一个 **私有** 仓库（如 `tavern-rules`），不用放任何文件
2. GitHub → Settings → Developer settings → **Fine-grained tokens** → 生成 token：
   - Repository access：只选这个私有仓库
   - Permissions：**Contents → Read and write**（其余不需要）
3. 在扩展「设置」页填入：用户名、仓库名、数据文件名（默认 `rules.json`）、token
4. 点「⟳ 立即同步」。其他设备装同一扩展、填同样信息，打开面板即自动拉取

> token 只保存在本机酒馆的扩展设置中，不会写入仓库、不会随导出文件外发。规则内容存在私有仓库，公开的是代码仓库，两者互不影响。

## 数据位置

| 数据 | 位置 |
|---|---|
| 规则 / 区域 / 建筑 / 角色 / GitHub 配置 | 扩展设置 `rule-book-lite`（本机，跨聊天保留） |
